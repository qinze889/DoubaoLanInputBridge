连接电脑
  1. 在电脑打开声笺
    登录与手机相同的账号。
  2. 启用电脑助手
    电脑会出现在“我的设备”，保持声笺后台运行。
  3. 回到这里开始对话
    可以聊想法、看图片，也可以交给电脑做事。
传文字或文件到当前输入框
在电脑端展开“文件传输与自动粘贴”，扫描其中的文件传输码。固定公网模式支持手机流量连接；自动粘贴需要电脑系统权限。
