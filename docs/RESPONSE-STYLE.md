# 默认简明回复

声笺在云端模型入口内置统一表达提示词，并随每轮任务发送给执行器，适用于本机 Harness 的 Chat/Work 及当前图片问答。已有电脑客户端和持久会话从下一轮对话生效，无需重装、重新授权或重新扫码。

默认先给答案或结果，使用简单中文，结合整段会话回答。简单问题简答，讨论、比较、创作及复杂问题充分展开，不固定限制句数或30—80字。不寒暄、不复述问题、不重复总结，不主动展开无关背景和内部工具日志。工作完成、失败、未知或需要操作均如实说明。

用户要求详细解释、完整方案、代码或文稿时，按要求完整交付。篇幅目标是模型提示，不是强制裁切；不降低输出上限、不删工具参数、不截断结果、不额外调用模型压缩。原有工具权限、当前图片安全规则和结构化记忆整理继续保留。

入口按认证设备正在运行的自有 `assistant_chat` 任务识别，不把另一台设备的会话规则混用到普通模型 API。夜间整理的 JSON 工具合同不改变。

本轮检查覆盖设备作用域、原系统规则和用户原话保留、工具参数和输出上限不变、完整长文原样通过，以及当前图片安全规则与表达提示共存。真实模型样本另见 `research/RESPONSE-STYLE-VALIDATION.json`；提示词能改善默认表达，但不承诺所有回答严格等长。
