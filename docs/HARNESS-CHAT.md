# 本机统一 Chat / Work 与实时语音

手机扫码页“对话”直接连接本机 DeepSeek Harness。豆包登录态通道仅用于流式 ASR 与 TTS，不参与聊天回答、任务规划或工具选择。普通聊天、连续追问、照片和摄像头提问、电脑工作都提交到 `/assistant/chat`，不依赖“让电脑”前缀或先切换任务模式。

## 会话与工作

每个账号及所选电脑的浏览器标签页保存一个稳定会话 ID；云端 SQLite 的 `assistant_conversations` 固定账号与设备归属。本机将它映射到 Harness 真正的持久化 Session，当前版本通过常驻 SDK Agent 复用，运行时重启后用 `session/resume` 续接（旧版使用 `--session-id`），保留模型消息与工具结果，而不是只拼接上一条任务摘要。账号切换不能读取别人的会话，切换电脑会建立另一段会话。标签页关闭后本地 Session 仍保存，但新标签页会建立新对话；长期用户记忆继续由原本机记忆与夜间生活记忆提供。

每轮使用稳定任务 ID、请求幂等 ID、事件序号和设备本地执行日志；任务脱离手机前台继续执行，断线不自动重放。单个本机连接器串行执行各轮，前一项工作尚未完成时，新要求排队；“汇报进度”“取消当前任务”及审批口令使用原任务控制接口，可以立即查询或请求停止。停止播报或用户插话只中断声音和旧回复展示，不等于取消已经运行的电脑操作。下一轮附带打断提示，避免重播未听完内容或重做操作。

电脑必须在线、启用更新后的 Agent 且已授予任务能力。离线、未更新或多台电脑尚未选定时明确反馈，不悄悄改用另一套云端 Chat。Codex 仍可用于明确选择电脑后的独立工作；默认 Chat 始终使用 DeepSeek Harness。

## 识图

DeepSeek 是对话和工具编排主体。当前文字模型不宣称原生识图，而是由 Harness 调用自有 `see_user_image` 工具，使用账号所选 WorkBuddy 视觉模型识别本轮附件，再结合观察继续回答或执行文件、浏览器等工作。所选视觉模型随该轮冻结，保留24个经过验证的模型选项。

照片仍先归档，再提交引用。摄像头保留本地预览，普通提问时取一帧；不持续上传视频。视觉请求携带任务标识：服务端验证设备属于该账号、任务正运行且未请求取消、图片列表与本轮明确授权附件完全一致，再读取图片。普通任务 token 仍不能浏览生活照片；设备没有整个账号的图片读取权限。图片文字与视觉观察都标为不可信数据，不赋予电脑操作权限。

照片、画面、语音转写与回答按现有开关保存生活记录，晚间共同整理并同步本机。Harness 工具参数、内部日志、思考过程不自动进入生活记忆。

## 增量播报

自有 DSH 插件订阅 `agent/assistant-stream`，只发送主 Agent 的 `text-delta`，不发送思考或子代理私有流。云端通过带序号的 `task.delta` 返回，手机复用既有分句 TTS、音频队列、回声处理和打断机制。增量可能包含工作过程的简短汇报；失败后会提示核对任务，不据部分文本宣称操作成功。会话结果和工具执行以最终任务状态及实际产物为准。

## 验证

- 真实 Harness 两轮 Session 续接和增量输出，确认历史代号可回忆。
- 浏览器虚拟麦克风／摄像头：图片准备门控、ASR→Harness事件→早期播报、打断后丢弃旧增量、相机取帧、同一会话标识、晚间记录来源及退出隔离。
- 服务端：账号及电脑隔离、幂等冲突、离线/旧版连接器反馈、WebSocket心跳能力协商、图片任务范围与冻结模型。
- 实际本机看图写文件和后续读取的脱敏结果见 [验收证据](research/HARNESS-CHAT-VALIDATION.json)。手机扬声器与麦克风真实回声表现仍需用户体验；模拟测试不替代真机声学验收。
