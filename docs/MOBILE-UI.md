# 声笺 Web 2.0 预览版

版本 `2.0.0-preview.2`。固定入口仍为 `/shengjian/api/v2/console`，已有账号、浏览器登录态和扫码入口继续使用。网页版本独立于桌面安装版本，不需要重装或重新授予电脑辅助权限。

## 五个日常入口

| 入口 | 主要操作 |
| --- | --- |
| 对话 | 文字、实时对话、按键说话、拍照/上传、镜头提问，查看历史或开启新对话 |
| 创作 | 生成图片、编辑照片、语音描述、查看版本和继续修改 |
| 记录 | 时间线、每日回顾、记忆；离线记录后联网同步 |
| 工作 | 实际执行的电脑工作、待确认、结果和取消回执 |
| 我的 | 账号额度、模型偏好、记录设置、设备授权、连接帮助及版本 |

手机使用底部导航，宽屏转为左侧导航。对话输入器固定在阅读区底部；模型、照片、历史和设置按需进入。明暗主题跟随系统。新回答的首段文字到达后直接淡入主阅读区、放大显示，旧消息弱化；流式后续文字不反复播放动画。用户主动滚动或按翻页键后恢复普通阅读，可点“回到最新回答”返回。历史恢复不重播淡入；系统减少动态效果时直接显示。视觉聚焦不改变输入框焦点，也不增加模型或语音等待。

文字输入默认安静，开启语音时使用语音回复。模型[默认简明回复](RESPONSE-STYLE.md)，需要详细内容时可直接要求展开。

## 历史与后台工作

对话历史从云端已有持久化任务和控制回执恢复。刷新和查看历史只读，不重派任务、不重播声音、不重复写入生活记录。草稿按账号和会话临时保存在当前浏览器；退出登录后清除。历史支持继续对话、加载更早对话与消息、归档和恢复。搜索针对已加载的对话标题。

新对话建立独立会话；新对话会停止当前语音并解绑本轮界面监听，已经提交的电脑工作仍继续。切换页面时，实时对话可通过底部提示条返回或结束。工作页只统计实际调用电脑工具或需要确认的任务，单纯聊天和识图不计为工作。取消请求仍必须收到电脑回执；结果未知不自动重试。

进度、取消和电脑状态等控制对话单独保存，重复请求返回同一回执，避免重试取消另一项新工作。任务结果保留完整文本，工具日志在运行详情中查看。

## 模型与记录

顶部模型名及“我的 → 模型偏好”可分别选择对话/工作、看图、生成图片、编辑图片模型。选项来自服务端已验证允许列表，偏好按账号保存。对话模型冻结在新任务中，切换不改变已开始的任务；Codex 仍使用其自身模型配置。

创作有明确的“生成图片 / 编辑照片”模式。创作区语音直接作为该模式的需求；进度询问不提交新图片。离开页面也会继续生成，回来可查看作品、选择历史版本继续修改。原参考记录删除时，仍可使用已保存的生成 PNG；不会悄悄重新生图。

记录以时间线为默认入口，回顾和记忆分别查看。记忆先阅读，点“编辑”后修改；编辑中的文本不会被轮询覆盖。删除记录、记忆或撤销设备前有确认。记录中的“和声笺聊聊”也进入主对话的同一本机 Harness。

## 数据升级与验证

独立 core SQLite 增量增加 `tasks.is_work`、`conversation_views`、`conversation_controls` 和按账号/会话的索引；既有用户、设备、登录态、任务事件及额度账本留在原库。旧任务按实际工具和确认事件回填分类。生活数据库不迁移。本次仅部署云端和网页，正式桌面版本仍以 Releases 为准。

后端覆盖历史归属、分页、升级回填和控制请求幂等。浏览器覆盖 320/390/1100 宽度、明暗主题、会话刷新、草稿、归档、返回键、后台任务、取消回执、模型选择、图片编辑、记录与账号隔离；CI 保存 `artifacts/product-ui/` 与 `artifacts/core-ui/` 截图。虚拟麦克风/摄像头不能替代手机免提和系统键盘的真机体验。
