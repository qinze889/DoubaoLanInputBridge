## 当前分发建议

当前推荐分发文件：

```text
dist/DoubaoLanInputBridge_zh2en.exe
```

不要一起分发以下本机运行数据：

```text
%LOCALAPPDATA%\DoubaoLanInputBridge
run_data*
local_update_source
任何包含 API Key 或访问 Key 的文件
```

这些数据应由每台电脑首次运行时自行生成或单独配置。
