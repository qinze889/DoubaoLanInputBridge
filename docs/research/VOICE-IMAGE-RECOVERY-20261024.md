## 故障与处理

本机 Agent 在线，但原测试号的真实 SDK 请求返回 HTTP 402 `insufficient_credits`。检查时可用应用积分 25、历史预留 497。按照用户“给测试号无限积分”的明确要求，增加管理员独立测试额度标志与幂等审计；原账号已开启，不用修改历史预留伪造余额。新调用仍记录用量，但不占用或扣减余额。切换权限时按每次调用开始时冻结的模式结算。

生成语句中的“不要文字”曾被前端误当成否定生成；携带参考图的请求也没有可用编辑路径。本版修正路由，增加真实 Images Edits 适配、持久版本与父图依赖。协议失败不会自动退回纯文字生图，结果未知不会自动重试。
