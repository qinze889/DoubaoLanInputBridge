# Mac 开发版固定公网文字传输

2026-10-24。用户明确需要公网文字发送／自动粘贴。本轮直接配置并接通已有固定公网传输服务，不以语音控制台代替文字传输。

检查发现正式版已有 relay 配置，开发版没有。为开发版单独登记中转设备，避免两个安装身份争用同一轮询队列；通过已有本机配置导入接口直接启用 public 模式。凭据仅保存至用户私有配置，0600，不进入报告或仓库。服务器签发前已保存私有恢复点。原正式版设备未修改。

已验证：原生运行服务返回 public / online；手机 HTTPS 登录成功；公网到实际桌面文件 API 往返成功；文字 `/send` 的空输入到实际桌面校验后返回 400，没有触发键盘输入。真实公网手机页面显示已连接，发送按钮可用，凭据片段从地址栏移除，刷新继续保持登录。配置重启后复用，设备码不按两分钟语音免登录票据到期；手机 Cookie 为既有 30 天，撤销设备会失效。

自动粘贴尚未验收：本机系统返回 accessibility=false，已请求用户为 /Applications/声笺开发版.app 开启辅助功能。没有向未知前台窗口发送测试文字，也没有声称实际粘贴成功。本轮未重新签名、覆盖 App 或切换正式版身份。

用户应扫描“文件传输与自动粘贴”区域内的文件传输二维码，语音区二维码用途不同。这里的 public 模式使用既有服务器，不需要用户自行部署或手工寻找 relay.json。
