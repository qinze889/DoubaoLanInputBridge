How to use DoubaoLanInputBridge

Send text, images, and small files between your phone and this Windows PC through the local network.

First run

1. Start the app
Double-click DoubaoLanInputBridge_zh2en.exe.
2. Scan the QR code
Keep phone and PC on the same Wi-Fi, then scan the QR code in the desktop app.
3. Send content
Use the phone page to send text, images, PDFs, Word files, and other small files.

Optional MiniMax API Key

Prompt enrichment needs a MiniMax API Key. In the desktop app, click Config, paste the key, and confirm. The key stays on this PC.

Troubleshooting

  • If the phone cannot open the page, confirm phone and PC are on the same Wi-Fi.
  • If Windows Firewall prompts, allow private network access.
  • If the port is occupied, the app automatically tries the next port.
  • Click Copy diagnostics and send the copied text to the maintainer when asking for help.
