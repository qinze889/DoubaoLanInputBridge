声笺 macOS 原生版 1.3.0 — 安装说明

1. 将「声笺」拖入旁边的 Applications 文件夹，然后在「应用程序」中双击打开。
2. 系统设置 → 隐私与安全性 → 设备控制和数据访问（旧版系统称辅助功能）：允许「声笺」。
   原生版由「声笺」主程序执行粘贴，不必单独授权内部 bridge-service。
   本地临时签名的新版可能使旧授权失效：移除旧的「声笺」条目，再添加 /Applications/声笺.app 并开启。
3. 首次运行请允许本地网络访问。
4. 已配置 relay.json 时使用 47 服务器固定入口；其他情况使用 Cloudflare 公网连接。
   显示「公网已连接」后扫码，手机蜂窝网络也可使用。
   关闭「公网连接」开关可切回同一 Wi-Fi 的局域网连接。
5. Mac 光标放到目标输入框，手机输入后点「发送」。

支持文字、图片、视频、普通文件互传；右上角「分享」可从 Mac 分享文字和文件。
“机器共享”可配对多台 Mac，经各自的公网隧道互传文件；邀请五分钟内有效且仅使用一次。
关闭窗口后仍在菜单栏运行；菜单栏选择「退出」或按 ⌘Q 完全退出。

当前安装包适用于 Apple Silicon，macOS 14.4 或以上。
本地 ad-hoc 签名构建，未做 Apple Developer ID 公证。如系统要求验证，
请在「系统设置 → 隐私与安全性」中选择「仍要打开」。无需关闭 Gatekeeper。

数据目录：~/Library/Application Support/DoubaoLanInputBridge/
无法连接：检查同一 Wi-Fi、本地网络授权、防火墙入站权限及路由器 AP 隔离。
自动粘贴需要目标应用支持 ⌘V；没有焦点时请先点击目标输入框。
手机页面可取消「发送后回车」。

基于 qinze889/DoubaoLanInputBridge 的本地 macOS 适配。

47 服务器入口地址固定。Cloudflare 临时域名则随重新连接变化，关闭或退出后失效。
