# 本地电脑助理

开发版侧栏进入“电脑 Agent”。执行引擎为内置的 DeepSeek Harness，模型沿用 sub-buddy；不是切换为其他厂商的桌面 Agent。

## 独立后台浏览器

“独立后台浏览器，不占用前台”默认开启。网页任务使用本机已安装 Chrome / Edge 的独立 headless profile，通过公开 CDP 连接。不会接入用户已打开的浏览器、复用用户 Cookie 或发送桌面键鼠事件。主代理和每个子代理使用独立 profile 与快照；子代理浏览器最多三份，任务结束后关闭其拥有的进程。浏览器登录态与用户日常浏览器独立。

工具提供 navigate、observe、click、fill；只允许 HTTP(S) 导航，不暴露任意脚本执行。页面内容按不可信数据处理，密码/文件/隐藏字段拒绝写入，下载被禁用。每次操作使快照失效，需重新观察才能确认结果。当前只处理主文档的可见控件，不保证跨域 iframe、验证码、系统原生文件对话框或任意网站均可操作。

## Mac 原生控件

“允许 Mac 应用后台控件操作（实验）”开关默认关闭。当前默认范围是计算器、文本编辑和 Safari；通过独立本机 API 可以调整 bundle ID 范围。原生 App 需要系统辅助功能授权。仅允许本机认证服务调用原生 UNIX socket；Harness 子进程不继承该 socket 的路径与密钥。子代理不能调用原生控件；网页必须使用后台浏览器。

Harness 使用 `mac_desktop` 后台打开应用、读取 AX 控件树、点击控件或填写非密码字段，不主动激活窗口；open_url 拒绝并要求改走后台浏览器。某些应用不支持后台 AX，不能将此能力泛化为任意软件的独立虚拟桌面。控件快照最多 160 个节点、8 层、2 秒采样，20 秒后过期；返回给模型前精简无效字段及默认不需要的菜单。每次点击/填写后快照立即失效。打开或点击的回执只说明请求发出，必须重新观察才能报告结果。该实现没有桌面屏幕截图、坐标鼠标或 Windows UI Automation。

安全边界：只应将可信操作交给桌面 Agent。网页和控件文字作为不可信数据；本工具不应处理密码、交易、对外发送、账户安全变更或破坏性操作。普通代码/文件操作仍走 Harness 自身的权限与单次审批流程。

示例：“在独立后台浏览器查询网页并汇报标题”。前台版本的计算器测试曾实际点击，但因上下文耗尽未完成；用户要求后台后已关闭前台路线，不将该次测试记为完整计算通过。

## 子代理、消息与技能

复用内置 MIT Harness 0.2.1-rc.2 的子代理 spawn/fork、list_agents、send_message 与父子完成通知，上限三子代理、委派深度一层。外层电脑任务仍串行，共享文件写入由主代理负责；并行浏览器按子代理隔离。子代理的消息能力限于 Harness 许可的父子关系，不代表独立云端任务可以任意互发消息。完整跨任务会话邮箱尚未接入。

首批自有技能为 background-web、computer-report、task-workspace，通过内置 skill-filesystem 按需发现/加载。禁用默认全局技能根目录，仅扫描本 App 内置目录和 App 数据目录 `agent/skills`。不隐式导入用户其他 Agent 的全部技能。MCP client 仅随 Harness 安装，尚未配置第三方服务；界面明确标为未配置。

## 本地记忆

App 数据目录 `agent/personal/personal.sqlite3` 使用独立 SQLite WAL，目录 700、数据库 600，按已登记设备 ID 隔离。记忆只在显式添加时保存，可以删除；不采集整个屏幕、文件或聊天历史作为长期记忆。数据库软删除保留恢复可能，不是安全擦除。

开关“任务使用本地记忆”控制是否将最多 12 条、4000 字的记忆作为模型上下文。持久化文件留在本机；启用上下文时相关文字仍会发送给模型。不要将“本地存储”理解为模型完全离线。声笺语音任务本身也会经过云端任务服务。常见凭据关键词会拒绝保存，这不是完整敏感信息检测。

手机示例：“记住：回复先讲结果，再讲细节”。可在电脑界面查看或删除。

## 报告与定时任务

“汇报今天电脑情况”或“生成今日汇报”直接读取本机 CPU、内存、磁盘、累计网络字节及当前 Agent 任务数，写入任务目录 `日报/` 并通过任务结果回复手机。这是执行时的状态快照，没有持续记录全天应用活动。

界面支持每日 `HH:mm`、`Asia/Shanghai` 时区定时任务；本机接口还支持一次性 epoch 时间。语音支持“每天9点汇报今天电脑情况”“每天09:30生成今日汇报”。用户明确添加并启用后才会运行；可暂停/删除。

调度器随 App 的 Agent 服务运行，每 5 秒检查。SQLite 事务按任务及当地日期领取唯一执行槽；重启时未完成的领取标为结果未知，禁止自动重放。错过 60 秒的时段、离线时段不补跑。提交的任务云端最多等待 30 秒，桌面执行前也检查期限，防止重连或本机排队后迟到的操作。网络提交结果不明确时标为 unknown，不自动重试。暂停或删除日程不等于取消已经发送的任务，应另行取消任务。

Mac 关闭窗口后保持服务运行时日程仍有效；退出 App、电脑休眠或 Agent 停止时不能保证触发。当前没有系统唤醒、离线推送或设备关机后的后台执行。

## 测试与发行

开发版采用临时签名，二进制更新可能再次触发 macOS 的辅助功能确认。稳定升级复用仍需 Developer ID 正式签名及真机覆盖升级验收；不能靠修改 TCC 数据库或冒用正式版身份解决。

Windows 源码提供同风格的记忆/定时界面，原生桌面控制尚未实现；需 Windows 安装包和真实设备另行验收。
