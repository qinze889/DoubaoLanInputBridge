声笺 Windows 1.3.0 — Mac / Windows 互联

推荐运行 Shengjian-windows-x64-setup.exe 安装 Tauri 正式版。
Shengjian-windows-x64.exe 是 Qt 便携版，二选一运行即可。
安装包内置 cloudflared，无需另装 Python 或配置 Cloudflare 账号。

1. Windows 打开「机器共享」，开启「公网连接」并等待就绪。
2. Mac 打开声笺「机器共享」，同样等待公网连接就绪。
3. 在任一端生成一次性邀请，在另一端粘贴配对。邀请五分钟内有效。
4. 配对后两端均可选择文件发送，接收完成后会校验 SHA256。

Mac 1.2.0 的机器共享协议兼容 Windows 1.3.0。
同一局域网可使用局域网邀请；Windows 需允许声笺的防火墙入站连接。
跨网络请让两端都开启公网连接。临时域名变化后可能需要重新配对。
接收文件在应用数据目录 received 中，界面提供「接收文件夹」。

Windows 文件名中的保留名称、不支持的字符和超长名称会自动调整。
源码与数据目录说明见仓库 docs/MACHINE-SHARING.md。
