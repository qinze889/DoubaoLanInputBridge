声笺 Windows 1.4.0 — Mac / Windows 互联

推荐运行 *-windows-x64-setup.exe 安装 Tauri 正式版。
*-windows-x64.exe 是 Qt 便携版，二选一运行即可。
安装包内置 cloudflared，无需另装 Python 或配置 Cloudflare 账号。

1. Windows 和 Mac 均在「连接方式」选择可达的入口并等待就绪。
   固定公网 / P2P 先导入后台为本机生成的 relay.json，每台机器使用独立配置。
   CF 隧道使用临时 HTTPS 域名；局域网适合同一 Wi-Fi / 内网。
2. 在任一端「机器共享」生成一次性邀请，在另一端粘贴配对。邀请五分钟内有效。
3. 配对后两端均可选择文件发送，接收完成后校验完整文件 SHA256。
4. P2P 需要两端均选 P2P，且 UDP / NAT 允许直连；失败请手动切换固定公网或 CF。
   P2P 不配置 TURN，不会自动退回服务器传文件。

旧版机器共享协议仍兼容 Mac 1.2.0 / Windows 1.3.0；P2P 需要两端使用 1.4.0。
局域网连接需允许声笺的防火墙入站访问。
跨网络请让两端都建立可达入口。CF 临时域名变化后可能需要重新配对。
固定公网使用同一域名下独立的设备编号，可区分多台电脑。
接收文件在应用数据目录 received 中，界面提供「接收文件夹」。

Windows 文件名中的保留名称、不支持的字符和超长名称会自动调整。
手机发送前先在电脑点选目标输入框；Windows 通过 Ctrl+V 粘贴。
不要公开设备配置、完整二维码或配对邀请。
源码与数据目录说明见仓库 docs/MACHINE-SHARING.md。
